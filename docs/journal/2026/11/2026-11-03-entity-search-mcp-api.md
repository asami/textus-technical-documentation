# Entityの標準検索をMCPとAPIへ提供する

Date: 2026-11-03
Status: ユーザーの機能説明を文書へ反映

## 確定した説明

- Entityのモデルとインスタンスを知識としてMCPで公開する。
- RDFの関係・条件検索とembeddingの意味的類似検索の対象はインスタンスである。モデルも同じ検索対象とする先行説明は採用しない。
- インスタンス検索はMCPとAPIの両経路から基本機能としてデフォルトで利用でき、個別の公開・検索コードを必要としない。
- MCP／APIは利用経路、RDF／embeddingは検索機構であり、両者を同列の検索方式として扱わない。
- モデルの意味とインスタンスの対応、参照権限を保持する。検索できることと更新できることは別の契約である。

## 更新

知識利用ガイドのCoreに検索経路のStep・claims・flowを追加し、日英本文・SmartDox・対応表を同期した。標準の公開・検索を個別構築するように読める初稿の文と、汎用経路を一律に未完成とする説明を改めた。通常のEntity検索に個別実装が必要という意味にはしない。

## 根拠と確認範囲

2026-11-03の本チャットでのユーザーの機能説明を根拠とする。以前の仕様調査だけから導いた限定を、この明示された基本機能に合わせて修正した。ソースのCore参照、日英構造、本文と表の対応を確認する。APIパスやMCPツール名は推測で追加していない。実装・実環境の動作確認、Cozyネイティブ検証、HTML・PDF生成は今回実施しない。
