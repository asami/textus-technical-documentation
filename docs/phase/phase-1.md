# Phase 1: Document Component Foundation and Security Guide

Status: PLANNED

## Goal

Establish the Textus Technical Documentation Component and publish the initial Textus/CNCF Security Architecture Technical Guide from SmartDox source.

## Scope

- establish internal `docs/` and product `src/main/` boundaries;
- establish SmartDox multilingual/multi-format conventions;
- generate Web/HTML, Markdown/text and PDF representations;
- package normal release representations in a Documentation CAR;
- expose document identity, description, reading/search and artifact information through the standard Component/MCP information surface;
- use the Security Technical Guide as the first reference document.

## Acceptance

A clean consumer can obtain one released document identity, select a supported language/format, read/search it through the Component information surface, and obtain the matching PDF without requiring the authoring workspace.
