# ライブプロトタイピング

本書は、SimpleModelingの技術で実現し得るソフトウェア開発の将来像を探る思考実験です。顧客の相談を受けたソリューション・エンジニアが、客先で一件の注文を一緒に試し、翌日のα版につなげるベスト・シナリオを扱います。焦点は、訪問前から再利用できる知識と実行基盤があり、対話で決まった業務規則だけを変更して試し直せる条件です。

相談と共同試作 → 業務規則のモデル化 → 部品の接続とAI補完 → α版での検証

開発全体での位置付けは[開発方法](../development-methods/README.md)、モデルから実行までの技術的なつながりは[Textus/CNCFの全体像](../../technical-guide/overview/textus-cncf-overview.dox/README.md)を参照してください。
