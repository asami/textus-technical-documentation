# Textus/CNCF 非機能要求と品質属性 技術ガイド

非機能要求と品質属性を入口に、モデル・コンポーネント・共通実行基盤の組合せによる品質上の効果を説明する。標準のモデルと機能の利用から品質対策が適用されることを主眼に、用途固有の条件、配備・設定、確認方法を整理する。

- `content/core.yaml`: 共通の論理構造。
- `content/ja/document.yaml`, `content/en/document.yaml`: 日英の説明と図表。
- `index.dox`: 同期した日英SmartDox本文。
- `images/`: 全体像ガイドから再利用した概念図2点の日英PNGとPlantUML原稿。
- `build/document-project-targets.yaml`: 日本語ロジックツリー・本文HTMLの生成対象。

初稿は9章、表5点、図2点。Coreの参照と日英本文・表の一致を確認済み。日本語PDF（7ページ）を生成し、Google Driveの@Activeへ配置済み。確認HTMLは未生成。

図は全体像ガイド（`src/main/smartdox/technical-guide/overview/textus-cncf-overview.dox/images/`）の既存図版を再利用した。出典と関連ガイドの対応はjournalに記録。
